# Ethics and Scope

ReportForge is a documentation and reporting engine for authorized penetration tests, Red Team exercises, purple team engagements, and security assessments.

It does not perform exploitation, scanning, credential collection, persistence, stealth activity, denial-of-service testing, destructive actions, or unauthorized reconnaissance. The tool only reads structured report data and exports professional documentation.

## Intended Use

- Create reusable report projects for authorized assessments.
- Document executive summaries, scope, timelines, technical findings, evidence, severity ratings, and remediation guidance.
- Generate bilingual English and Portuguese reports.
- Export Markdown and HTML artifacts suitable for internal delivery, portfolio samples, and documentation workflows.
- Reuse report data generated by other safe and authorized security tooling.

## Out of Scope

- Exploit development or execution.
- Credential theft, token harvesting, or secret extraction.
- Malware, persistence, evasion, or stealth abuse.
- Unauthorized scanning or target interaction.
- Destructive testing or denial-of-service activity.

## Evidence Handling

Use synthetic datasets for public demos. Keep sensitive client artifacts in approved storage, reference them safely, and redact evidence before placing reports in public repositories or portfolio material.

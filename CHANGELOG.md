- Final stable release of the bilingual pentest reporting engine.
- Added production-ready Typer CLI commands for project creation, finding insertion, validation, export, redaction, metrics, schema generation, finding listing, and local doctor checks.

- Added synthetic English and Portuguese example data, GitHub Actions CI, Makefile automation, contribution guide, security policy, usage guide, template guide, architecture notes, roadmap, JSON schema, and release notes.
